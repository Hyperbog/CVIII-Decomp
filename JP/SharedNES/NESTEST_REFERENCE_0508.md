# External 6502 CPU Golden Trace — nestest harness (2026-10-09)

**Status: independent test harness, not ROM-specific gameplay parity.** Kevin Horton's `nestest.nes` and the accompanying Nintendulator `nestest.log` are used as **test-time dependencies**, downloaded at a pinned public repository revision; neither the executable nor its 8991-line trace is committed to the Castlevania decomp repository. Primary references: [NESdev Emulator tests](https://www.nesdev.org/wiki/Emulator_tests), [nestest 2004 author's documentation](https://github.com/christopherpow/nes-test-roms/blob/95d8f621ae55cee0d09b91519a8989ae0e64753b/other/nestest.txt), [golden log](https://github.com/christopherpow/nes-test-roms/blob/95d8f621ae55cee0d09b91519a8989ae0e64753b/other/nestest.log), [test ROM](https://github.com/christopherpow/nes-test-roms/blob/95d8f621ae55cee0d09b91519a8989ae0e64753b/other/nestest.nes).

## Scope

`JP/tools/test_nestest_external_0508.py` adapts the existing original-project `trace_6502_vrc6_0508.CPU` and `trace_cycle_vblank_0508.base_cycles` under an NROM-only memory bus. It starts in the documented **automation mode at CPU `$C000`** with A/X/Y=0, P=`$24`, SP=`$FD`, CPU cycles=7. This is deliberately **not** the test cartridge reset vector (which starts the interactive menu). It compares original-reference **preinstruction** PC, A, X, Y, P, SP, and CPU cycle count on each line, rejecting any unsupported opcode, first divergence, missing field or truncated run.

The independent reference was recorded from Nintendulator, **not from our Python CPU implementation**. The hardware model is standard NES 2A03 without decimal ADC/SBC behavior. The ROM-free smoke regression uses synthetic NROM code and short golden rows. CI: `.github/workflows/jp-nestest-reference.yml` downloads the pinned assets into a temporary workspace; Git contains only the runner, tests, documentation, and SHA-only results. SHA256 of the fetched test files is recorded by CI and can be separately pinned after the first run.

**Limitations:** nestest uses NROM; passing this CPU trace does **not** prove Castlevania III's mapper-24 VRC6 bank scheduling, video, IRQ/NMI, sprite-zero hits, audio or gameplay state. The fixed rubric's **CPU/bank/interrupt trace-comparison** requirement remains unearned until an actual Japanese game reference execution is compared. Strict 0507 PRG floor 49,404/262,144 (18.8461%), VPP 25/100, fixed frontier FB96, and the last completed semantic checkpoint 0507 are not modified by these independent CPU tests.
