# JP 0594 — Native F10 stage/companion debug menu

The prior stage/companion selector was an external manual password
generator. JP0594 adds a true **in-game** F10 UI for the owner's native
Windows Alpha, independently of Original or Enhanced presentation.
The windowed SDL host overlay is generated by
`tools/patch_cyc_stage_menu_0594.py` from the already patched 0591
external host. It is applied only in private windowed CMake builds.

## Controls

| Key | Effect |
|---|---|
| F10 | Open/close the debug menu; pause game |
| Up/Down | Select one of 18 save-point labels |
| Left/Right | Select None, Alucard, Sypha or Grant |
| Enter | Load the complete previously captured machine checkpoint |
| F5 | Capture the **current** game machine under selected label |
| Escape | Close menu, leave game unchanged |

The UI is drawn *after* original game picture is copied to the SDL
renderer; hardware frame hashes and screenshot parity are unaffected.
F8/F9 10-slot saves are unchanged. Checkpoint files use the same
owner-ROM-specific saves directory, plus suffix
`.debug.stageNN.partnerN.cycstate`. A missing/incompatible file is
rejected by NESRecomp's existing atomic load validator. On success,
the original load_state_from() resets host frame count and notifies
the original session.

**Deliberate safety boundary:** This is a checkpoint warp, not arbitrary
first-run stage creation. The user must capture each stage/companion
machine state once (by reaching it through gameplay or the game's
password screen). Selecting a companion does not inject one into RAM,
and selecting a stage doesn't initialize unvisited level resources.
Labels must match the stage/companion actually present at capture;
the UI does not yet prove labels against game RAM. Avoid overwriting
checkpoints with mislabeled states. Save-file acceptance is tied to
the exact generated game executable and machine structure.

No ROM patches, fake PPU/mapper resets or speculative game-state pokes
are made. Full arbitrary initial stage/companion selection requires
independent JP-password accept/init trace or full reference checkpoints.
ROM-free anchor smoke plus pinned external synthetic Windows compile
are the build gates. Original-JP GUI playtest remains pending. Strict
PRG coverage = 49,504/262,144; VPP 27/100; recovery state 0508
and PRG31 $FB96 frontier unchanged.
