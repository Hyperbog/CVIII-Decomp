# 0510 — Faithful native structured lift of original live actor-event row $32

**Classification: validated source-semantic native gameplay slice; active research, NOT a full game and NOT a new strict PRG-byte certificate.** Original Japanese Mapper 24 ROM SHA-256 `958a4b5e95e80acb2c71a43e9ef2e91444f3d097ae9d4eeb747f0dac8abe7a28`. Independent original Mesen2 2.1.1 reaches this handler naturally with raw bank `$0A` mapped at Stage 1, frame 3092.

## What has actually been lifted

`JP/src/actor_event_row32_0510.{hpp,cpp}` implements a *structured C++ state transition*, not a virtual 6502 CPU or a host-engine approximation. The caller must supply the six-source-object index X and original RAM `$69=X`, event row `$07C2,X=$32` and event low nibble `$07C8,X&$0F=0`. The source original dispatch word is `$8523+2*$32 -> $8B26 -> $8B2C`; these two pointer words are separately ROM authenticated.

Source sequence: `$8501-$8520` two-level pointer resolution; `$8B2C` guard `$07E0,X`; `$8D5E-$8D75` source coordinates `$07DA,X/$07D4,X`, script/type tables `$9194+row`/`$91EC+row` (original values `$13/$3D`); `$8DC1-$8DE6` count matching type `$3D` among actor destination slots 1–8 with a maximum of 3; fixed `$FF06` first free of 12 destination slots; `$8D76-$8D90` original eighteen-field fixed `$FF24` reset then write `$0400/$0438/$041C/$05EF/$054E`; `$9244` attribute indexed by type (`$067B,X=$01`); raw bank `$0B:$A00F` original AI table choice (`$0657,X=$20`, both relevant row-$3D alternatives agree); `$8B50-$8B73` actor attribute `$0470` bit2, source reference `$0645` and packed high-nibble event index; `$85D8` event index increment. Original temporary-bank helper RAM `$24` is also preserved.

Source return when indexed `$07E0,X` is nonzero leaves allocator fields unchanged after the dispatcher scratch writes. Capacity failure when three matching types exist in destination slots 1–8, or all 12 are occupied, takes original `$8B48` behavior, **setting the full source event byte to `$02`**, not incrementing it. These alternate branches have synthetic native unit coverage; their genuine original-game liveness is not claimed.

## Regression, source authentication, future work

The ROM-free C++ [unit test](../tests/actor_event_row32_0510_test.cpp) covers **all 4,096** 12-slot occupancy combinations, six source indices with guarded entry, six actor-type-cap examples, and three incorrect-entry rejections: **4,111 cases**. Native CTest and Linux AddressSanitizer/UndefinedBehaviorSanitizer pass. The lift is compiled into the existing `standalone0509` native actor/OAM library and the `JP/tools/run_native_regressions.sh` gate. The standalone demonstration is *not* proof of whole-game parity.

The original-JP-ROM optional audit separately hash-locks seven raw-bank `$0A/$0B` code/data spans and five original indexed data values. Reproduce with the user-supplied ROM and matching Mesen-agent 2.1.1:

```sh
cmake -S JP/standalone0509 -B build/standalone0509 -DCMAKE_BUILD_TYPE=Release
cmake --build build/standalone0509 --parallel
ctest --test-dir build/standalone0509 --output-on-failure
python3 JP/tools/audit_native_row32_live_0510.py "$ORIGINAL_JP_ROM" \
  --mesen /path/to/mesen-agent \
  --native-replay build/standalone0509/native_row32_replay_0510 \
  --report /tmp/jp0510_row32_native_live.json
```
