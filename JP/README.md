# CVIII-Decomp

Faithful reverse engineering and native-PC recompilation/decompilation project for the Japanese NES release **Akumajou Densetsu** (Castlevania III), using the verified Mapper 24 / Konami VRC6a ROM as immutable source evidence.

Active development is on the `decompilation` branch. See `docs/DECOMPILATION_CONTINUITY.md` and `docs/PROGRESS.md` there before continuing work.

**Shared mod-forward policy:** [Universal Mod-Forward Development Methodology](../MOD_FORWARD_METHODOLOGY.md) governs new game systems, data, UI, audio, save compatibility and future editors across all ports, not just NES. The [JP Enhanced implementation plan](docs/ENHANCED_MODDING_ARCHITECTURE.md) specializes those principles for this game. Only Enhanced ships, with original Japanese gameplay as its vanilla behavioral baseline; proposed mod APIs/editor features are not claimed as implemented.

Current player-facing feature status and priorities: [Enhanced Edition status](docs/ENHANCED_CURRENT_STATUS.md). The owner's corrected graphical report is archived in [closed issue #1](https://github.com/Hyperbog/CVIII-Decomp/issues/1).

The original ROM is **not** stored in this repository.
