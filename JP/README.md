# CVIII-Decomp

Faithful reverse engineering and native-PC recompilation/decompilation project for the Japanese NES release **Akumajou Densetsu** (Castlevania III), using the verified Mapper 24 / Konami VRC6a ROM as immutable source evidence.

Active development is on the `decompilation` branch. See `docs/DECOMPILATION_CONTINUITY.md` and `docs/PROGRESS.md` there before continuing work.

The original ROM is **not** stored in this repository.
