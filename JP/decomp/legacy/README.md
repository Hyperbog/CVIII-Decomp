# Preserved early C++ experiments (not current native game)

The original JP0509–0510 C++ experiments are retained here for
reproducible research and historical tests. They are **not**
the real Japanese ROM-backed NESRecomp game, and their historic
graphical demonstrations do not replace original Castlevania III.
Build paths were updated without changing their source algorithms:

- [native0509](native0509/) — 6502/mapped-bus partial CPU test.
- [standalone0509](standalone0509/) — synthetic actor/sprite pipeline.
- [native_demo0510](native_demo0510/) — authored preview demonstration.

Active builds still use [native NESRecomp](../../native/nesrecomp_cycle/)
and [the Enhanced launcher](../../release/alpha/).
